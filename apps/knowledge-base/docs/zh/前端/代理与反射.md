## 代理与反射

Proxy 与 Reflect 是 ES6 引入的一对配套元编程 API：Proxy 负责拦截对象的底层操作，Reflect 提供与这些操作对应的标准化默认实现。二者通常配合使用，是实现响应式系统、数据校验、权限控制等高级特性的核心基础
### Proxy

`Proxy` 用于拦截对象的所有基本内部操作，例如读取、赋值、删除、函数调用和构造；

```
const proxy = new Proxy(target, handler);
```

- target：被代理的目标对象，支持任意对象类型（普通对象、数组、函数、类、甚至另一个 Proxy 实例）。
- handler：捕获器配置对象，其属性是对应操作的拦截函数。空 handler 会创建 “透明代理”，所有操作直接转发给目标对象。
- proxy：返回的代理对象，外部所有通过 proxy 的操作都会触发拦截。

Proxy 不会修改目标对象本身，而是在代理对象这一层拦截操作。直接访问 `target` 会绕过代理，不会触发任何捕获器。

```
const target = {
  name: "Alice",
};

const proxy = new Proxy(target, {
  get(target, property, receiver) {
    console.log(`读取 ${String(property)}`);
    return Reflect.get(target, property, receiver);
  },
});

proxy.name; // 记录读取操作并返回 "Alice"
```

### Proxy 捕获器

Proxy 支持 13 种捕获器，分别对应对象的 13 种底层内部操作：
#### get

拦截属性读取操作：通过点语法、方括号语法、`Reflect.get()` 访问属性的场景，在原型链继承过程中读取属性时也会触发该捕获器。

接收 target、property、receiver 三个参数：

- target：被代理的原始目标对象
- property：被读取的属性名
- receiver：最初接收读取操作的对象，一般是代理对象；原型继承场景里，receiver 会是子类实例。当访问继承自原型链上的属性时，this 绑定就由 receiver 决定，而不是 target；

返回值可以是任意类型，将作为属性读取的结果返回给调用方。

示例：实现数组负索引

```
const arr = [1, 2, 3];
const proxyArr = new Proxy(arr, {
  get(target, prop) {
    const index = Number(prop);
    if (index < 0) {
      return target[target.length + index]; // 负索引转换
    }
    return Reflect.get(target, prop);
  }
});

proxyArr[-1]; // 3
proxyArr[0];  // 1
```

#### set

拦截属性赋值操作： `proxy.prop = value`、`proxy['prop'] = value`、`Reflect.set()` 等赋值形式，所有对代理对象的属性写入都会经过该捕获器。

接收 target、property、value、receiver 四个参数：

- target：被代理的原始目标对象
- property：要赋值的属性名（字符串 / Symbol）
- value：准备赋予该属性的值
- receiver：最初接收赋值操作的对象，通常是代理对象本身；原型继承场景下为子类实例，决定赋值操作里的 `this` 指向；

返回值为布尔类型，表示本次赋值操作是否成功，在严格模式下，返回 false 会触发 TypeError 异常。

示例：属性类型校验

```
const user = { name: "Alice", age: 18 };
const proxyUser = new Proxy(user, {
  set(target, prop, value, receiver) {
    if (prop === "age" && !Number.isInteger(value)) {
      throw new TypeError("age 必须是整数");
    }
    return Reflect.set(target, prop, value, receiver);
  }
});

proxyUser.age = 20;   // 成功
proxyUser.age = "abc"; // 抛出 TypeError
```

#### has

拦截属性存在性判断操作：对应 `property in proxy` 运算符，同时 `with` 语句中的属性存在性检查也会触发该捕获器。

接收 target、property 两个参数：

- target：被代理的原始目标对象
- property：需要检测的属性名（字符串 / Symbol） 返回布尔值，表示属性是否存在。

返回值为布尔类型，用于表示目标属性是否存在于对象中。

示例：隐藏下划线开头的私有属性

```
const obj = { _private: 1, public: 2 };
const proxy = new Proxy(obj, {
  has(target, prop) {
    if (prop.startsWith("_")) return false;
    return Reflect.has(target, prop);
  }
});

"_private" in proxy; // false
"public" in proxy;   // true
```

#### deleteProperty

拦截属性删除操作：对应 `delete proxy[property]` 语法执行的属性删除行为。

接收 target、property 两个参数：

- target：被代理的原始目标对象
- property：要删除的属性名

返回值为布尔类型，表示本次属性删除操作是否成功。

示例：保护私有属性不可删除

```
const proxy = new Proxy(obj, {
  deleteProperty(target, prop) {
    if (prop.startsWith("_")) return false;
    return Reflect.deleteProperty(target, prop);
  }
});

delete proxy._private; // false，删除失败
delete proxy.public;   // true，删除成功
```

#### ownKeys

拦截获取对象自有属性键的相关操作：`Object.keys()`、`Object.getOwnPropertyNames()`、`Object.getOwnPropertySymbols()`、`Reflect.ownKeys()`，以及 `for...in` 循环对自有属性的遍历过程。

接收 target 一个参数：被代理的原始目标对象；

返回值为数组，包含对象所有自有属性的键名；

示例：过滤私有属性使其不可枚举

```
const proxy = new Proxy(obj, {
  ownKeys(target) {
    return Reflect.ownKeys(target).filter(key => !String(key).startsWith("_"));
  }
});

Object.keys(proxy); // ["public"]
```

#### getOwnPropertyDescriptor

拦截获取对象自有属性描述符的操作：对应`Object.getOwnPropertyDescriptor(proxy, property)` 的调用行为，当外部尝试获取代理对象某个属性的详细配置（可写、可枚举、可配置等）时会触发该捕获器。

接收 target、property 两个参数：

- target：被代理的原始目标对象
- property：查询的属性名

返回值为属性描述符对象，若目标属性不存在则返回 undefined。

示例：隐藏私有属性的描述符

```
const obj = { _private: 1, public: 2 };
const proxy = new Proxy(obj, {
  getOwnPropertyDescriptor(target, prop) {
    if (prop.startsWith("_")) return undefined;
    return Reflect.getOwnPropertyDescriptor(target, prop);
  }
});

Object.getOwnPropertyDescriptor(proxy, "_private"); // undefined
Object.getOwnPropertyDescriptor(proxy, "public");
// { value: 2, writable: true, enumerable: true, configurable: true }
```

#### defineProperty

拦截定义或修改对象属性的操作，对应 `Object.defineProperty(proxy, property, descriptor)` 的调用行为，外部通过该方法新增或修改属性的配置时会经过该捕获器。

接收 target、property、descriptor 三个参数：

- target：被代理的原始目标对象；
- property：要定义或修改的属性名；
- descriptor：属性描述符对象（包含 value、writable、enumerable、configurable 等配置）；

返回值为布尔类型，表示本次属性定义或修改操作是否成功。

示例：禁止定义下划线开头的私有属性

```
const obj = {};
const proxy = new Proxy(obj, {
  defineProperty(target, prop, descriptor) {
    if (prop.startsWith("_")) return false;
    return Reflect.defineProperty(target, prop, descriptor);
  }
});

Object.defineProperty(proxy, "public", { value: 1, enumerable: true }); // 操作成功
Object.defineProperty(proxy, "_private", { value: 2 }); // 捕获器返回 false，Object.defineProperty() 直接抛出 TypeError，与严格模式无关
```

#### getPrototypeOf

拦截获取对象原型的相关操作：`Object.getPrototypeOf()`、访问 `__proto__` 属性、`instanceof` 运算符判断以及 `Reflect.getPrototypeOf()` 调用，所有尝试读取代理对象原型的行为都会触发该捕获器。

接收 target 一个参数：被代理的原始目标对象；

返回值为对象或者 null，代表目标对象的原型。

示例：原型访问日志与 instanceof 验证

```
const parent = { type: "parent" };
const target = Object.create(parent);
const proxy = new Proxy(target, {
  getPrototypeOf(target) {
    console.log("触发原型读取操作");
    return Reflect.getPrototypeOf(target);
  }
});

Object.getPrototypeOf(proxy); // 打印"触发原型读取操作"，返回 { type: "parent" }
proxy instanceof Object; // 打印"触发原型读取操作"，返回 true
```

#### setPrototypeOf

拦截设置对象原型的操作，对应 `Object.setPrototypeOf()` 和 `Reflect.setPrototypeOf()` 的调用行为，外部尝试修改代理对象的原型时会触发该捕获器。

接收 target、prototype 两个参数：

- target：被代理的原始目标对象；
- prototype：要设置的原型对象，可以是 `null`；

返回值为布尔类型，表示原型设置操作是否成功。

示例：禁止修改对象原型

```
const target = {};
const proxy = new Proxy(target, {
  setPrototypeOf(target, prototype) {
    console.log("拒绝修改原型");
    return false; // 拒绝原型修改操作
  }
});

Object.setPrototypeOf(proxy, { a: 1 }); // 捕获器返回 false，Object.setPrototypeOf() 直接抛出 TypeError，与严格模式无关
Object.getPrototypeOf(proxy); // 仍为原始的 Object.prototype
```

#### isExtensible

拦截判断对象是否可扩展的操作，对应 `Object.isExtensible()` 和 `Reflect.isExtensible()` 的调用行为，外部检查代理对象能否新增属性时会触发该捕获器。

接收 target 一个参数：被代理的原始目标对象；

返回值为布尔类型，代表目标对象是否支持扩展新属性。

示例：可扩展性检查日志

```
const target = {};
const proxy = new Proxy(target, {
  isExtensible(target) {
    console.log("执行对象可扩展性检查");
    return Reflect.isExtensible(target);
  }
});

Object.isExtensible(proxy); // 打印"执行对象可扩展性检查"，返回 true
```

#### preventExtensions

拦截让对象变为不可扩展的操作：对应 `Object.preventExtensions()` 和 `Reflect.preventExtensions()` 的调用行为，外部尝试关闭对象的属性扩展能力时会触发该捕获器。

接收 target 一个参数：被代理的原始目标对象；

返回值为布尔类型，表示阻止扩展操作是否成功。

示例：关闭扩展前的日志提示

```
const target = { value: 1 };
const proxy = new Proxy(target, {
  preventExtensions(target) {
    console.log("即将关闭对象的扩展能力");
    return Reflect.preventExtensions(target);
  }
});

Object.preventExtensions(proxy); // 打印"即将关闭对象的扩展能力"
Object.isExtensible(proxy); // false，对象已不可扩展
```

#### apply

拦截函数调用操作：包括直接调用 `proxy(...args)`、`proxy.call()`、`proxy.apply()` 以及 `Reflect.apply()` 等函数调用形式，仅当目标对象为函数类型时生效。

接收 target、thisArgument、argumentsList 三个参数：

- target：被代理的原始函数；
- thisArgument：函数调用绑定的 this；
- argumentsList：调用参数数组；

返回值可以是任意类型，作为函数调用的结果返回。

示例：函数调用日志与结果增强

```
function sum(a, b) { return a + b; }
const proxiedSum = new Proxy(sum, {
  apply(target, thisArg, args) {
    console.log(`调用 sum，参数：${args.join(", ")}`);
    const result = Reflect.apply(target, thisArg, args);
    return result * 2; // 返回值翻倍
  }
});

proxiedSum(1, 2);
// 控制台输出：调用 sum，参数：1, 2
// 返回结果：6
```

#### construct

拦截构造函数调用操作：对应 `new proxy(...args)` 和 `Reflect.construct()` 的构造调用场景，仅当目标对象为构造函数时生效。

接收 target、argumentsList、newTarget 三个参数：

- target：被代理的原始构造函数；
- argumentsList：new 传入的参数数组；
- newTarget：最初被 new 调用的构造函数，决定实例原型；

返回值必须是对象类型，作为构造调用生成的实例。

示例：给实例自动添加创建时间

```
function Person(name) { this.name = name; }
const ProxiedPerson = new Proxy(Person, {
  construct(target, args, newTarget) {
    const instance = Reflect.construct(target, args, newTarget);
    instance.createdAt = new Date();
    return instance;
  }
});

const alice = new ProxiedPerson("Alice");
alice.createdAt; // 时间对象
```

### Proxy 不变量

Proxy 可以通过捕获器拦截对象的底层操作，但不能随意篡改 JavaScript 对象模型的固有语义。ECMAScript 规范为每个捕获器定义了必须遵守的强制约束，这些约束就叫做 Proxy 不变量；

不变量的核心作用是：保证代理对象的行为在底层语义上与真实对象保持一致，不会破坏 JS 对象模型的基本可信度。一旦捕获器违反不变量，JS 引擎会直接抛出 `TypeError`；

常见捕获器规则：

- get ：当目标对象的某个自有数据属性同时满足不可写、不可配置时，get 捕获器返回的结果必须与该属性的原始值严格相等，不能返回任意其他值。如果目标对象上存在不可配置的访问器属性，且该属性没有定义 getter，get 捕获器也必须返回 undefined，不能随意返回其他内容。

- set ：如果目标对象存在不可配置且不可写的自有数据属性，且新值与原值不同，set 捕获器不能返回代表赋值成功的真值；如果目标对象存在没有 setter 的不可配置自有访问器属性，set 捕获器也不能返回真值。仅仅因为目标对象不可扩展且属性不存在，并不会构成 set 捕获器的不变量；

- deleteProperty 捕获器的不变量规则：如果目标对象对应的自有属性是不可配置的，deleteProperty 捕获器不能返回代表删除成功的真值，必须返回假值。

- has 捕获器的不变量规则：如果目标对象的某个自有属性是不可配置的，has 捕获器不能返回假值来隐藏该属性的存在。如果目标对象不可扩展，目标已有的所有自有属性都不能被 has 捕获器隐藏，必须返回真值。

- defineProperty 捕获器的不变量规则：如果目标对象不可扩展，不能通过 defineProperty 捕获器给目标新增不存在的属性。同时不能把目标上原本可配置的属性修改为不可配置，也不能凭空定义一个不存在的不可配置属性。

例如，不可配置且不可写的数据属性不能被 `get` 捕获器报告为其他值：

```
const target = {};
Object.defineProperty(target, "fixed", {
  value: 1,
  writable: false,
  configurable: false
});

const proxy = new Proxy(target, {
  get() {
    return 2; // 试图返回不同的值
  }
});

console.log(proxy.fixed);
// TypeError: 'get' on proxy: property 'fixed' is a read-only and non-configurable data property on the proxy target but the proxy did not return its actual value
```

### Reflect

Reflect 是 ES6 引入的内置静态对象，是 JavaScript 元编程体系的核心基础之一。它不可通过 new 调用，所有能力都以静态方法呈现，本质是将 JavaScript 引擎内部的对象底层操作封装为标准公开 API；

Reflect 的方法使用统一的函数调用形式，但返回值取决于具体操作：`Reflect.set()`、`Reflect.defineProperty()`、`Reflect.deleteProperty()`、`Reflect.preventExtensions()`、`Reflect.setPrototypeOf()` 返回布尔值表示成功与否；`Reflect.get()`、`Reflect.apply()`、`Reflect.construct()` 等分别返回读取值、调用结果或构造出的对象；

与 Proxy 的 13 种捕获器一一对应的方法

```
Reflect.get(target, property, receiver);
Reflect.set(target, property, value, receiver);
Reflect.has(target, property);
Reflect.deleteProperty(target, property);
Reflect.ownKeys(target);
Reflect.defineProperty(target, property, descriptor);
Reflect.getOwnPropertyDescriptor(target, property);
Reflect.getPrototypeOf(target);
Reflect.setPrototypeOf(target, prototype);
Reflect.isExtensible(target);
Reflect.preventExtensions(target);
Reflect.apply(fn, thisArgument, argumentsList);
Reflect.construct(Constructor, argumentsList, NewTarget);
```

与部分 `Object` 方法相比，Reflect API 更贴近底层操作，并使用统一的函数形式。

`Reflect.defineProperty()` 返回布尔值表示是否成功；`Object.defineProperty()` 失败时通常抛出异常。

```
const object = {};

Reflect.defineProperty(object, "value", {
  value: 1,
  writable: true,
}); // true

Reflect.deleteProperty(object, "value"); // true
```

### 可撤销Proxy

Proxy.revocable () 是 Proxy 的静态方法，用于创建一个可主动失效的代理对象。和普通 `new Proxy()` 直接返回代理实例不同，它会返回一个包含两个属性的对象：`proxy` 是生成的代理实例，`revoke` 是对应的撤销方法；

代理在被撤销前，行为与普通代理完全一致，可以正常访问目标对象的所有属性与方法。 调用 `revoke()` 方法后，代理对象会立即进入失效状态。此后对该代理执行任何对象底层操作，包括属性读写、原型访问、函数调用、枚举键名等，都会抛出 TypeError

```
const target = {
  value: 1,
};

const { proxy, revoke } = Proxy.revocable(target, {});

proxy.value; // 1

revoke();

// proxy.value; // TypeError
```

### 常见使用场景

数据校验：

```
function createValidatedUser(user) {
  return new Proxy(user, {
    set(target, property, value, receiver) {
      // 拦截赋值操作，执行前置校验
      if (property === "age" && (!Number.isInteger(value) || value < 0)) {
        throw new RangeError("age must be a non-negative integer");
      }
      // 校验通过，执行默认赋值逻辑
      return Reflect.set(target, property, value, receiver);
    },
  });
}

// 使用
const user = createValidatedUser({ name: "Tom", age: 18 });
user.age = 20;   // 正常赋值
user.age = -5;   // 抛出 RangeError
```

依赖追踪：

```
const dependencies = new Set(); // 用 Set 更合适，自动去重依赖
const state = new Proxy(
  { count: 0 },
  {
    get(target, property, receiver) {
      // 拦截读取操作，收集当前访问的属性作为依赖
      dependencies.add(property);
      return Reflect.get(target, property, receiver);
    },
  }
);

// 触发依赖收集
console.log(state.count);
console.log(dependencies); // Set(1) { 'count' }
```

私有属性保护：

```
function createPrivateObject(obj) {
  return new Proxy(obj, {
    get(target, prop) {
      if (prop.startsWith('_')) {
        throw new Error(`Cannot access private property: ${prop}`);
      }
      return Reflect.get(target, prop);
    },
    has(target, prop) {
      // 隐藏私有属性，in 运算符无法检测到
      if (prop.startsWith('_')) return false;
      return Reflect.has(target, prop);
    },
    deleteProperty(target, prop) {
      if (prop.startsWith('_')) {
        throw new Error(`Cannot delete private property: ${prop}`);
      }
      return Reflect.deleteProperty(target, prop);
    },
    ownKeys(target) {
      // 遍历时过滤私有属性
      return Reflect.ownKeys(target).filter(key => !key.startsWith('_'));
    }
  });
}

const user = createPrivateObject({ name: 'Alice', _password: '123456' });
console.log(user.name);       // Alice
console.log(user._password);  // 抛出错误
console.log('_password' in user); // false
console.log(Object.keys(user));   // ['name']
```
