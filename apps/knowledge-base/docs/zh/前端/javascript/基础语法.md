## 基础语法

### 语法基本规则

JavaScript 是一门区分大小写的语言，标识符、关键字、变量名均严格区分大小写，`myVar` 与 `myvar` 是两个不同的标识符。

**标识符**是用于命名变量、函数、属性等的名称，必须遵循以下规则：

- 首字符必须是字母、下划线（`_`）或美元符号（`$`）；
- 后续字符可以是字母、数字、下划线或美元符号；
- 不能使用保留字（关键字）作为标识符；
- 可以包含 Unicode 字符（如中文），但不推荐。

```
let _private = 1;
let $jquery = 'selector';
let userName = 'Alice';
```

JavaScript 会忽略多余的空格和换行，可以利用缩进和空行提高代码可读性。

### 分号与自动分号插入

JavaScript 语句通常以分号结尾，但分号在大多数情况下可以省略。JavaScript 引擎通过**自动分号插入（ASI, Automatic Semicolon Insertion）**机制在解析时自动补充分号。

ASI 的核心规则：

- 当遇到换行符，且下一个 token 无法与当前语句继续合法解析时，自动插入分号；
- `}` 之前自动插入分号；
- 程序输入结束时自动插入分号；
- `return`、`throw`、`break`、`continue`、`yield` 等受限产生式之后换行，会自动插入分号，导致后续代码被忽略。

```
// ASI 正常工作
let a = 1
let b = 2

// 危险：return 后换行，ASI 插入分号，函数返回 undefined
function bad() {
  return
    { name: 'Alice' };
}

// 危险：以 ( 或 [ 开头的行可能与上一行拼接解析
let x = 1
(function() {})()
// 被解析为 1(function() {})()，抛出 TypeError
```

最佳实践是始终手动书写分号，避免 ASI 带来的意外行为。

### 注释

JavaScript 支持两种注释方式：

- **单行注释**：以 `//` 开头，到行尾结束；
- **多行注释**：以 `/*` 开头，以 `*/` 结束，可以跨越多行。

```
// 这是单行注释

/*
  这是多行注释
  可以写很多行
*/

let count = 0; // 行尾注释
```

多行注释不能嵌套，`/*` 内部遇到第一个 `*/` 即结束。注释中的内容会被引擎完全忽略，不参与执行。

### 变量声明

JavaScript 提供三种变量声明方式：`var`、`let`、`const`。

**var**

- 函数作用域（非块级作用域）；
- 存在变量提升（hoisting），声明被提升到函数顶部，初始值为 `undefined`；
- 可以重复声明；
- 可重新赋值。

```
function example() {
  console.log(x); // undefined（提升）
  var x = 1;
  var x = 2; // 允许重复声明
  x = 3;     // 允许重新赋值
}
```

**let**

- 块级作用域（`{}` 内有效）；
- 存在提升，但在声明之前访问会抛出 `ReferenceError`（暂时性死区 TDZ）；
- 不允许在同一作用域内重复声明；
- 可重新赋值。

```
{
  // console.log(y); // ReferenceError: Cannot access 'y' before initialization
  let y = 1;
  // let y = 2;     // SyntaxError: Identifier 'y' has already been declared
  y = 2;             // 允许重新赋值
}
```

**const**

- 块级作用域；
- 声明时必须初始化；
- 不允许重新赋值（变量绑定不可变）；
- 对于对象和数组，其内部属性和元素仍可修改（引用不可变，值可变）。

```
const PI = 3.14159;
// PI = 3;           // TypeError: Assignment to constant variable

const person = { name: 'Alice' };
person.name = 'Bob';  // 允许修改对象属性
person.age = 20;      // 允许添加新属性

const arr = [1, 2, 3];
arr.push(4);           // 允许修改数组元素
```

**声明选择建议**：默认使用 `const`，只有确定需要重新赋值时才使用 `let`；避免使用 `var`，其函数作用域和提升行为容易引发难以察觉的 bug。

> 作用域、闭包、变量提升的详细内容参见「作用域与函数」文档。

### 数据类型概述

JavaScript 有 8 种数据类型，分为原始类型（primitive）和对象类型（object）两大类。

**原始类型**（7 种）：

- `undefined`：未定义，变量声明但未赋值时的默认值；
- `null`：空值，表示刻意赋值的"无"；
- `boolean`：布尔值，`true` 或 `false`；
- `number`：数字，包含整数和浮点数（IEEE 754 双精度 64 位）；
- `string`：字符串，不可变的 UTF-16 字符序列；
- `symbol`：符号，ES6 引入的唯一不可变原始值；
- `bigint`：大整数，ES2020 引入，用于表示任意精度整数。

**对象类型**：

- `object`：对象，包含普通对象、数组、函数、日期、正则等所有非原始值。

使用 `typeof` 运算符可以检测值的类型：

```
typeof undefined;    // "undefined"
typeof null;         // "object"（历史遗留 bug）
typeof true;         // "boolean"
typeof 42;           // "number"
typeof "hello";      // "string"
typeof Symbol();     // "symbol"
typeof 10n;          // "bigint"
typeof {};           // "object"
typeof function(){}; // "function"
```

> 类型系统、类型判断、装箱拆箱、类型转换的详细内容参见「类型系统」文档。

### 操作符

操作符（运算符）用于对值进行运算和操作，JavaScript 拥有丰富的操作符集合。

#### 算术操作符

| 操作符 | 名称 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `3 + 2` | `5` |
| `-` | 减法 | `3 - 2` | `1` |
| `*` | 乘法 | `3 * 2` | `6` |
| `/` | 除法 | `7 / 2` | `3.5` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 指数 | `2 ** 3` | `8` |
| `++` | 自增 | `let x=1; x++` | `x=2` |
| `--` | 自减 | `let x=2; x--` | `x=1` |

`+` 操作符具有加法和字符串拼接双重行为：当任一操作数为字符串时执行字符串拼接，否则执行数值加法。

```
1 + 2;        // 3（数值加法）
"1" + 2;      // "12"（字符串拼接）
1 + "2";      // "12"
1 + 2 + "3";  // "33"（先算 1+2=3，再拼接 "3"）
```

自增/自减有前置和后置两种形式，区别在于返回值：

- 前置（`++x`）：先自增，返回新值；
- 后置（`x++`）：返回旧值，再自增。

```
let a = 1;
console.log(++a); // 2（先增后用）
console.log(a);   // 2

let b = 1;
console.log(b++); // 1（先用后增）
console.log(b);   // 2
```

#### 赋值操作符

| 操作符 | 示例 | 等价于 |
|--------|------|--------|
| `=` | `x = 5` | — |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `%=` | `x %= 3` | `x = x % 3` |
| `**=` | `x **= 3` | `x = x ** 3` |

ES2021 引入了逻辑赋值操作符，结合逻辑运算与赋值：

| 操作符 | 示例 | 等价于 |
|--------|------|--------|
| `\|\|=` | `x \|\|= y` | `x \|\| (x = y)` |
| `&&=` | `x &&= y` | `x && (x = y)` |
| `??=` | `x ??= y` | `x ?? (x = y)` |

```
let name = '';
name ||= '默认名';  // name 为 ''（falsy），赋值为 '默认名'

let count = 0;
count ??= 10;       // count 为 0（不是 null/undefined），不赋值，仍为 0
```

#### 比较操作符

| 操作符 | 名称 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 相等（宽松） | `1 == "1"` | `true` |
| `===` | 严格相等 | `1 === "1"` | `false` |
| `!=` | 不等（宽松） | `1 != "1"` | `false` |
| `!==` | 严格不等 | `1 !== "1"` | `true` |
| `>` | 大于 | `3 > 2` | `true` |
| `<` | 小于 | `3 < 2` | `false` |
| `>=` | 大于等于 | `3 >= 3` | `true` |
| `<=` | 小于等于 | `3 <= 2` | `false` |

**宽松相等（`==`）**会在比较前进行类型转换，可能产生反直觉的结果：

```
0 == '';             // true
null == undefined;   // true
false == 0;          // true
NaN == NaN;          // false（NaN 不等于任何值，包括自身）
```

**严格相等（`===`）**不进行类型转换，类型不同直接返回 `false`，是推荐使用的比较方式。

> 类型转换与比较的详细规则参见「类型系统」文档。

#### 逻辑操作符

| 操作符 | 名称 | 行为 |
|--------|------|------|
| `&&` | 逻辑与 | 左操作数为 falsy 时返回左操作数，否则返回右操作数 |
| `\|\|` | 逻辑或 | 左操作数为 truthy 时返回左操作数，否则返回右操作数 |
| `!` | 逻辑非 | 将操作数转为布尔值后取反 |

逻辑操作符具有**短路求值**特性：当左侧操作数已经能确定结果时，不会执行右侧操作数。

```
// && 短路：左侧为 falsy 时不执行右侧
let x = 0;
false && (x = 1);  // x 仍为 0

// || 短路：左侧为 truthy 时不执行右侧
let y = 0;
true || (y = 1);   // y 仍为 0

// 常见用法：设置默认值
let name = userName || '匿名';

// 常见用法：安全访问
obj && obj.method && obj.method();
```

**falsy 值**（转为 `false` 的值）共有 8 个：`false`、`0`、`-0`、`0n`、`""`、`null`、`undefined`、`NaN`。其余所有值均为 truthy。

ES2020 引入了**空值合并操作符 `??`**，仅在左操作数为 `null` 或 `undefined` 时返回右操作数：

```
let count = 0;
count || 10;  // 10（0 是 falsy）
count ?? 10;  // 0（0 不是 null/undefined）
```

#### 一元操作符

| 操作符 | 名称 | 示例 | 说明 |
|--------|------|------|------|
| `typeof` | 类型检测 | `typeof 42` | 返回类型字符串 |
| `void` | 求值返回 undefined | `void(0)` | 求值表达式但返回 undefined |
| `delete` | 删除属性 | `delete obj.x` | 删除对象属性或数组元素 |
| `+` | 一元加 | `+"42"` | 将操作数转为数字 |
| `-` | 一元减 | `-"42"` | 转为数字并取负 |
| `~` | 按位非 | `~5` | 按位取反 |
| `!` | 逻辑非 | `!true` | 取反 |

```
+"42";       // 42（字符串转数字）
+true;       // 1
- "5";       // -5
!!"hello";   // true（双重取反，转为布尔值）
typeof "hi"; // "string"
```

#### 条件（三元）操作符

三元操作符是 `if...else` 的简写形式，语法为 `条件 ? 表达式1 : 表达式2`：

```
let age = 20;
let status = age >= 18 ? "成年" : "未成年";  // "成年"

// 可嵌套（但不建议过深，影响可读性）
let score = 85;
let grade = score >= 90 ? "A" : score >= 80 ? "B" : "C";  // "B"
```

#### 可选链操作符

ES2020 引入的可选链操作符 `?.` 用于安全访问嵌套属性，当中间属性为 `null` 或 `undefined` 时，表达式短路返回 `undefined`，不会抛出错误：

```
let user = { name: 'Alice' };
user.address?.city;              // undefined（不报错）
user.address?.city ?? '未知';    // "未知"

// 也可用于函数调用和数组访问
obj.method?.();
arr?.[0];
```

#### 操作符优先级

当表达式中包含多个操作符时，JavaScript 按照操作符优先级决定执行顺序。优先级高的先执行，优先级相同的按结合性（左结合或右结合）执行。

常见操作符优先级（从高到低）：

| 优先级 | 操作符 | 说明 |
|--------|--------|------|
| 最高 | `()` | 分组 |
| | `?.` | 可选链 |
| | `!` `~` `+` `-` `typeof` `void` `delete` | 一元操作符 |
| | `**` | 指数（右结合） |
| | `*` `/` `%` | 乘除取余 |
| | `+` `-` | 加减 |
| | `<` `<=` `>` `>=` | 关系比较 |
| | `==` `!=` `===` `!==` | 相等比较 |
| | `&&` | 逻辑与 |
| | `\|\|` `??` | 逻辑或/空值合并 |
| | `?:` | 三元（右结合） |
| | `=` `+=` `-=` 等 | 赋值（右结合） |
| 最低 | `,` | 逗号 |

```
2 + 3 * 4;       // 14（先乘后加）
(2 + 3) * 4;     // 20（括号改变优先级）
2 ** 3 ** 2;     // 512（右结合，先算 3**2=9，再算 2**9）
a = b = 5;        // 右结合，a 和 b 都为 5
```

对于复杂表达式，建议使用括号明确优先级，提高可读性和可维护性。

### 语句与表达式

**表达式**（expression）是会产生值的代码单元，任何可以写在赋值号右侧的都是表达式：

```
1 + 2;              // 表达式，值为 3
"hello";            // 表达式，值为 "hello"
function() {};      // 函数表达式
x = 5;              // 赋值表达式，值为 5
```

**语句**（statement）是执行某个动作的代码单元，本身不产生可用的值：

```
if (x > 0) { }                       // if 语句
for (let i = 0; i < 10; i++) { }    // for 语句
return x;                             // return 语句
let y = 1;                            // 变量声明语句
```

表达式后面加上分号就成为**表达式语句**，是最常见的语句类型：

```
console.log("hello");  // 表达式语句
a = b + c;             // 表达式语句
```

**块语句**（`{}`）将多个语句组合为一个语句块，块级作用域变量（`let`、`const`）在块外不可访问：

```
{
  let x = 1;
  const y = 2;
  console.log(x + y);  // 3
}
// console.log(x);  // ReferenceError
```

### 控制流语句

#### 条件语句

**if...else**

```
if (condition) {
  // 条件为 truthy 时执行
} else if (otherCondition) {
  // 其他条件
} else {
  // 所有条件都不满足时执行
}
```

条件表达式会被自动转为布尔值，falsy 值（`0`、`""`、`null`、`undefined`、`NaN`、`false`）进入 else 分支。

**switch**

`switch` 语句根据表达式的值匹配对应的 `case` 分支，使用**严格相等**（`===`）比较：

```
switch (day) {
  case 1:
    console.log("星期一");
    break;
  case 2:
    console.log("星期二");
    break;
  default:
    console.log("其他");
}
```

注意事项：

- 不写 `break` 会发生**穿透**（fall-through），继续执行下一个 case 的代码；
- 穿透有时是故意的，用于多个 case 共享同一段代码；
- `default` 分支可以放在任意位置，建议放在最后。

```
// 利用穿透：多个 case 共享代码
switch (month) {
  case 1:
  case 3:
  case 5:
    console.log("31天");
    break;
  case 2:
    console.log("28或29天");
    break;
}
```

#### 循环语句

**for 循环**

```
for (初始化; 条件; 迭代) {
  // 循环体
}

for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}
```

三个表达式均可省略，但分号不能省略，全部省略时为无限循环：

```
for (;;) {
  // 无限循环
}
```

**while 循环**

```
while (条件) {
  // 条件为 truthy 时重复执行
}

let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
```

**do...while 循环**

与 while 的区别：先执行一次循环体，再检查条件，因此循环体至少执行一次：

```
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 5);
```

**for...in 循环**

遍历对象的可枚举属性（包括继承的属性），不推荐用于数组遍历（顺序不保证、会遍历出自定义属性）：

```
let obj = { a: 1, b: 2, c: 3 };
for (let key in obj) {
  console.log(key, obj[key]);  // a 1, b 2, c 3
}
```

**for...of 循环**

ES6 引入，用于遍历可迭代对象（数组、字符串、Map、Set、Generator 等），遍历的是值而非键：

```
let arr = [10, 20, 30];
for (let value of arr) {
  console.log(value);  // 10, 20, 30
}

for (let char of "hello") {
  console.log(char);  // h, e, l, l, o
}
```

> 迭代器与生成器的详细内容参见「迭代器与生成器」文档。

#### break 与 continue

- `break`：立即终止当前循环或 switch 语句；
- `continue`：跳过当前迭代的剩余代码，直接进入下一次循环条件判断。

```
for (let i = 0; i < 10; i++) {
  if (i === 3) continue;  // 跳过 3
  if (i === 7) break;     // 到 7 时终止
  console.log(i);          // 0, 1, 2, 4, 5, 6
}
```

`break` 可以配合标签（label）跳出外层循环：

```
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) {
      break outer;  // 直接跳出外层循环
    }
    console.log(i, j);
  }
}
```
