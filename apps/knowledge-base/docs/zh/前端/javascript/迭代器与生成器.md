## 迭代器与生成器

迭代器（Iterator）和生成器（Generator）是 JavaScript 中处理序列数据的核心机制，它们基于标准化的迭代协议，让不同数据结构拥有了一致的遍历方式，同时支持惰性求值、状态暂停等高级特性。

### 迭代与遍历

遍历：是一种访问行为，指按顺序访问一组数据中的每一个成员，核心关注 “数据访问” 这个动作本身。遍历的前提是数据已经完整存储在集合中，比如用 `for` 循环按索引访问数组、用 `forEach` 遍历数组，都属于遍历；

迭代：是一种行为模式，定义了 “如何按需逐个产生下一个值” 的统一接口，核心关注 “值的产生方式”。迭代不要求数据提前全部存在，也不要求消费者了解数据的内部存储结构

遍历是迭代的典型应用场景，针对已存在的有限数据集合，目标是按序访问每一个元素；

数组可以通过索引遍历，也可以通过迭代器消费：

```
const values = ["a", "b", "c"];
const iterator = values[Symbol.iterator]();

iterator.next(); // { value: "a", done: false }
iterator.next(); // { value: "b", done: false }
iterator.next(); // { value: "c", done: false }
iterator.next(); // { value: undefined, done: true }
```

### 迭代器

迭代器协议：约束迭代器对象必须提供 `next()` 方法，每次调用 `next()` 都返回一个固定结构的 `IteratorResult` 对象：`{ value: 当前迭代值, done: 布尔值 }`；

迭代器：是遵循迭代器协议的对象，核心作用是维护迭代的进度状态，每次调用 `next()` 就会推进到下一个位置，返回当前值和结束状态；

自迭代（既是迭代器也是可迭代对象）：JavaScript 中绝大多数内置迭代器（比如数组迭代器、生成器对象），都额外实现了 `Symbol.iterator()` 方法，并且返回 `this` 自身：

```
const iterator = [1, 2, 3][Symbol.iterator]();

// 迭代器自己也部署了 Symbol.iterator
typeof iterator[Symbol.iterator]; // "function"
// 调用后返回自身
iterator[Symbol.iterator]() === iterator; // true

// 因此迭代器本身也能直接用 for...of 消费
for (const v of iterator) {
  console.log(v); // 1 2 3
}
```

手写一个基础迭代器：

```
function createArrayIterator(values) {
  let index = 0;
  return {
    next() {
      if (index < values.length) {
        return {
          value: values[index++],
          done: false,
        };
      }
      return {
        value: undefined,
        done: true,
      };
    },
  };
}

const iterator = createArrayIterator(["a", "b", "c"]);
console.log(iterator.next()); // { value: "a", done: false }
console.log(iterator.next()); // { value: "b", done: false }
console.log(iterator.next()); // { value: "c", done: false }
console.log(iterator.next()); // { value: undefined, done: true }
```

迭代器可选方法：

- `return(value)`：可选方法。迭代被提前终止时（如 `for...of` 中遇到 `break`、`return` 或循环体抛出异常）会被语言机制调用，用于执行清理工作（关闭文件、释放连接等）。该方法必须返回一个对象，通常返回 `{ value, done: true }`，但协议并不强制 `done` 必须为 `true`；
- `throw(error)`：可选方法。向迭代器内部抛出错误，通常配合生成器使用；若迭代器内部未捕获错误，错误会向外层抛出；

```
const iterable = {
  [Symbol.iterator]() {
    return {
      next() { return { value: 1, done: false }; },
      return() {
        console.log("迭代提前结束，执行清理");
        return { value: "cleanup", done: true };
      }
    };
  }
};

for (const v of iterable) {
  console.log(v); // 1
  break; // 触发 return() 方法
}
```

### 可迭代对象

可迭代协议：对象必须部署 `[Symbol.iterator]()` 方法，该方法无参数，调用后必须返回一个迭代器；

可迭代对象：是遵循可迭代协议的对象；

JavaScript 原生默认部署了 `Symbol.iterator`、天然支持迭代的对象包括：Array、String、Map、Set、arguments等；

所有支持迭代协议的语法，都会自动调用对象的 `Symbol.iterator` 方法获取迭代器，完成遍历。常见的消费方式包括：`for...of`、数组展开、数组解构、`Array.from()`、 `Promise.all(iterable)` 等 Promise 组合方法；

注意：对象展开 `{ ...object }` 使用对象属性枚举规则，不使用迭代器协议；

普通字面量对象默认没有部署 `Symbol.iterator`，因此不能直接用迭代语法消费：

```
const object = {
  a: 1,
  b: 2,
};

// for (const value of object) {} // TypeError
```
### Symbol.iterator

`Symbol.iterator` 是迭代机制的统一接口，用于创建并返回一个迭代器，所有遵循迭代协议的语法（`for...of`、展开运算符、解构赋值等），都会自动读取这个属性，调用它获取迭代器，进而完成遍历；

```
const range = {
  start: 1,  // 迭代起始值
  end: 3,    // 迭代结束值

  // 部署 Symbol.iterator 方法：可迭代协议的要求
  [Symbol.iterator]() {
    // 闭包变量：维护当前迭代进度
    let current = this.start;
    const end = this.end;

    // 返回一个全新的迭代器对象（符合迭代器协议）
    return {
      // 迭代器必须实现的 next() 方法
      next() {
        if (current <= end) {
          // 迭代未结束：返回当前值 + 标记未完成
          return {
            value: current++,
            done: false,
          };
        }
        // 迭代结束：标记完成
        return {
          value: undefined,
          done: true,
        };
      },
    };
  },
};

// 可以直接用迭代语法消费
[...range]; // [1, 2, 3]
```

### 生成器

生成器是 ES6 引入的核心特性，它既是迭代器的语法糖，又具备函数暂停与恢复执行的能力，它完全遵循迭代协议，同时提供了更强大的流程控制能力；

生成器函数使用 `function*` 声明，调用生成器函数不会立即执行函数体，而是返回一个生成器：

```
function* createNumbers() {
  yield 1;
  yield 2;
  return 3;
}

const generator = createNumbers();
```

生成器对象天然同时实现了迭代器协议和可迭代协议：这意味着生成器对象可以直接被所有标准迭代语法消费

```
// 生成器本身就是迭代器：拥有 next 方法
typeof generator.next; // "function"

// 生成器本身也是可迭代对象：拥有 Symbol.iterator
generator[Symbol.iterator]() === generator; // true
```

#### yield

`yield expression` 暂停生成器，并把表达式结果作为本次 `next()` 的 `value` 返回；

`yield` 必须直接属于当前生成器函数，可以出现在该函数的 `if`、循环、`try` 等嵌套语句块中，但不能出现在生成器内部再次声明的普通函数、箭头函数或回调函数中；

```
function* example() {
  console.log("start");
  yield 1;
  console.log("middle");
  yield 2;
  console.log("end");
}

const generator = example();

generator.next(); // 输出 "start"，返回 { value: 1, done: false }
generator.next(); // 输出 "middle"，返回 { value: 2, done: false }
generator.next(); // 输出 "end"，返回 { value: undefined, done: true }
```

生成器的三个控制方法：

- `next()`用于启动或恢复生成器执行，同时支持向生成器内部传入值；
- `return()` 用于强制提前终止生成器，无论当前执行到哪个位置；
- `throw()` 用于在生成器当前暂停的 yield 位置抛出一个错误，实现错误的双向交互；

```
function* task() {
  try {
    yield "running";
  } finally {
    console.log("执行清理");
  }
}

const gen = task();
gen.next(); // { value: "running", done: false }
gen.return("终止");
// 先输出 "执行清理"
// 再返回 { value: "终止", done: true }
```
#### 委托迭代

`yield*` 用于将迭代过程委托给另一个可迭代对象，相当于把该可迭代对象的所有值逐个 `yield` 出来；

```
function* combined() {
  yield 0;
  yield* [1, 2, 3]; // 委托给数组迭代
  yield 4;
}

[...combined()]; // [0, 1, 2, 3, 4]
```

#### 双向传值

`yield` 既向外产生值，也可以从下一次 `next(value)` 接收值；

关键错位规则：第 n 次调用 `next(value)` 的参数，对应的是第 n-1 个 yield 表达式的返回值；

```
function* calculate() {
  const first = yield "请输入第一个数字";
  const second = yield "请输入第二个数字";
  return first + second;
}

const generator = calculate();

generator.next();
// { value: "请输入第一个数字", done: false }

generator.next(10);
// 10 成为第一个 yield 表达式的结果
// { value: "请输入第二个数字", done: false }

generator.next(20);
// { value: 30, done: true }
```

`return` 的值只会出现在手动调用 `next()` 得到的最终结果中，`for...of` 和展开语法不会收集生成器的 `return` 值。

```
function* values() {
  yield 1;
  return 2;
}

[...values()]; // [1]
```

### 异步迭代器

异步迭代器是 ES2018 引入的语言标准，专门用来处理异步产生的序列数据。它完全对标同步迭代器的设计逻辑，核心区别是把 “同步返回结果” 改成了 “异步返回 Promise”，让异步操作也能通过统一的迭代接口进行遍历；

异步迭代器协议：迭代器必须提供 `next()` 方法，每次调用 `next()` 都会返回一个 `Promise`；当异步操作完成后，Promise 会兑现为标准的 `IteratorResult` 结构：`{ value: 当前异步产出的值, done: 布尔值 }`；

异步可迭代协议：对象必须部署 `[Symbol.asyncIterator]()` 方法，该方法无参数，调用后必须返回一个异步迭代器；

异步迭代器是遵循异步迭代器协议的对象，核心作用是封装异步逻辑、维护迭代进度，按需异步产出值

```
const asyncIterator = {
  current: 0,
  // next 是异步方法，返回 Promise
  async next() {
    if (this.current < 3) {
      const value = this.current++;
      // 封装异步操作：模拟延时、网络请求、文件读取等
      await new Promise((resolve) => {
        setTimeout(resolve, 100);
      });
      // 异步操作完成后，返回标准结果
      return { value, done: false };
    }
    // 迭代结束
    return { value: undefined, done: true };
  },
};
```

异步可迭代对象是遵循异步可迭代协议的对象，它的定位是 “异步数据源”，通过 `Symbol.asyncIterator` 对外提供统一的迭代器获取入口；

```
const asyncIterable = {
  // 部署异步迭代入口
  [Symbol.asyncIterator]() {
    // 返回一个全新的异步迭代器，闭包维护独立状态
    let current = 0;
    return {
      async next() {
        if (current < 3) {
          await new Promise(r => setTimeout(r, 100));
          return { value: current++, done: false };
        }
        return { done: true };
      }
    };
  }
};
```

常见异步可迭代对象包括浏览器的ReadableStream、Node.js的Readable Stream等；
### for await...of

同步可迭代对象用 `for...of` 遍历，异步可迭代对象对应的标准消费语法是 `for await...of`；

```
async function run() {
  // 遍历异步可迭代对象
  for await (const value of asyncIterable) {
    console.log(value); // 间隔 100ms 依次输出 0, 1, 2
  }
}
run();
```

`for await...of` 也能消费同步 Iterable，它会把同步结果包装为异步结果。但逐项等待会增加开销，同步数据优先使用普通 `for...of`

```
async function printValues() {
  for await (const value of [1, 2, 3]) {
    console.log(value);
  }
}
```

### 异步生成器

异步生成器通过 `async function*` 语法声明（`async` 关键字 + 生成器的 `function*` 语法）：

```
// 异步生成器函数
async function* asyncGen() {
  // 内部可以使用 await 处理异步操作
  await new Promise(r => setTimeout(r, 100));
  // 用 yield 产出值
  yield 1;
  yield 2;
}
```

`yield` 后面可以跟随任意类型的值，包括普通值和 Promise。异步生成器的 `next()` 始终返回 Promise；如果 `yield` 的是 Promise，异步生成器会等待它完成，最终 `IteratorResult.value` 是兑现值而不是嵌套的 Promise；如果该 Promise 拒绝，`next()` 返回的 Promise 也会拒绝。

```
async function* demo() {
  yield Promise.resolve("直接 yield Promise");

  const res = await Promise.resolve("先 await 再 yield");
  yield res;
}

const gen = demo();
await gen.next(); // { value: "直接 yield Promise", done: false }
await gen.next(); // { value: "先 await 再 yield", done: false }
```

无论 `yield` 产出的是什么类型的值，调用异步生成器的 `next()` 方法，永远返回一个 Promise：

```
async function* demo() {
  yield 1; // 产出普通值
}

const gen = demo();
const result = gen.next();
console.log(result instanceof Promise); // true
result.then(res => console.log(res)); // { value: 1, done: false }
```
