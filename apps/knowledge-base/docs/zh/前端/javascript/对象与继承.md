## 对象与属性

### 属性键

ECMAScript 规范中，对象的属性键仅支持 String 和 Symbol 两种类型。如果使用数字、对象、布尔等其他类型作为键，会先执行隐式类型转换，转为字符串后再作为属性名（Map 的键没有该限制，可以直接使用任何类型的值作为键）；

```
const obj = {};
const key1 = { id: 1 };
const key2 = { id: 2 };

obj[key1] = "value1";
obj[key2] = "value2";

console.log(Object.keys(obj)); 
// ["[object Object]"]
// 两个对象都转成了 "[object Object]" 字符串，后者覆盖了前者
```

ES6 引入计算属性语法，支持在对象字面量中用 `[表达式]` 动态生成属性键：

```
const prefix = "user";
const user = {
  [`${prefix}_name`]: "Alice", // 字符串模板
  [1 + 2]: "索引键",          // 数值运算
  [Symbol("id")]: 1001        // Symbol 键
};
```


### 自有属性与继承属性

直接存在于对象自身的属性称为自有属性；对象自身没有，通过原型链从原型对象上继承访问到的属性；

| 方法                        | 判断范围    | 说明                                                       |
| ------------------------- | ------- | -------------------------------------------------------- |
| `key in obj`              | 自有 + 继承 | 只要原型链上存在该属性就返回 `true`                                    |
| `obj.hasOwnProperty(key)` | 仅自有     | 对象实例方法；风险：如果对象自身定义了同名的 `hasOwnProperty`方法，会屏蔽原型方法，导致判断失效 |
| `Object.hasOwn(obj, key)` | 仅自有     | ES2022 新增静态方法，推荐优先使用，避免原型屏蔽问题                            |

```
const parent = { inherited: 1 };
const child = Object.create(parent); // child 的原型指向 parent
child.own = 2;

// 自有属性
console.log(Object.hasOwn(child, "own"));       // true
// 继承属性
console.log(Object.hasOwn(child, "inherited")); // false

// in 运算符包含继承
console.log("own" in child);       // true
console.log("inherited" in child); // true
```

### 属性描述符

JavaScript 中每个属性都对应一个属性描述符对象，用于描述属性的元信息和行为规则。属性分为两类：数据属性和访问器属性，二者的描述符字段不同，且不能混用

**数据属性描述符**：用于存储一个可读写的具体值：

| 字段             | 说明                                              |
| -------------- | ----------------------------------------------- |
| `value`        | 属性存储的具体值                                        |
| `writable`     | 属性值是否可以被赋值修改                                    |
| `enumerable`   | 属性是否可枚举（是否会出现在 `for...in`、`Object.keys()` 等遍历中） |
| `configurable` | 属性是否可配置：能否删除属性、能否修改描述符、能否在数据 / 访问器属性间转换         |

**访问器属性描述符**：不存储具体值，通过 `getter/setter` 函数控制属性的读写：

| 字段             | 说明                  |
| -------------- | ------------------- |
| `get`          | 读取属性时触发的函数，返回值作为属性值 |
| `set`          | 写入属性时触发的函数，接收赋值作为参数 |
| `enumerable`   | 同数据属性               |
| `configurable` | 同数据属性               |


注意：使用 `Object.defineProperty()` 新建属性时，未指定的布尔字段默认都是 `false`；而通过对象字面量创建的普通属性，`writable`、`enumerable`、`configurable` 默认均为 `true`

```
const user = {
  firstName: "Ada",
  lastName: "Lovelace"
};

// 定义访问器属性 fullName
Object.defineProperty(user, "fullName", {
  enumerable: true,
  configurable: true,
  get() {
    return `${this.firstName} ${this.lastName}`;
  },
  set(value) {
    [this.firstName, this.lastName] = value.split(" ");
  }
});

console.log(user.fullName); // "Ada Lovelace"
user.fullName = "Alan Turing";
console.log(user.firstName); // "Alan"
```

### 属性的读取与查找

读取 `obj.key` 时，JavaScript 引擎会执行完整的原型链查找流程：

1. 先检查对象自身是否存在该属性，存在则返回对应值；
2. 不存在则沿内部的 `[[Prototype]]` 向上查找原型对象；
3. 逐级追溯直到 `Object.prototype.__proto__`（即 `null`）；
4. 整条原型链都找不到则返回 `undefined`。

属性值为 `undefined` 和属性本身不存在，读取结果都是 `undefined`，但本质完全不同，可以用 `Object.hasOwn()` 准确区分：

```
const object = { value: undefined };

object.value; // undefined
object.missing; // undefined

Object.hasOwn(object, "value"); // true
Object.hasOwn(object, "missing"); // false
```

### for...in 与对象遍历

`for...in` 遍历对象自身及原型链上所有可枚举的字符串属性键，但是不遍历 Symbol类型的属性键；

普通对象的属性键遍历顺序为：

1. 非负整数索引键：按数值升序排列；
2. 其他字符串键：按属性创建的先后顺序排列；
3. Symbol 键：按创建的先后顺序排列。

不应使用 `for...in` 遍历数组值，因为它得到的是字符串索引，还可能读到原型链上的可枚举属性；

只遍历对象自身数据时，通常优先使用 `Object.keys()`、`Object.values()` 或 `Object.entries()`；

```
const parent = { inherited: 1 };
const child = Object.create(parent);
child.own = 2;

for (const key in child) {
  if (Object.hasOwn(child, key)) {
    console.log(key, child[key]);
  }
}
```


### 浅拷贝与引用共享

浅拷贝只创建一个新的外层对象，嵌套的对象 / 数组仍然共享同一份引用。修改拷贝后的嵌套对象，原对象的嵌套对象也会同步改变

```
const original = {
  name: "Alice",
  address: {
    city: "Beijing"
  }
};

// 浅拷贝
const copied = { ...original };

// 修改嵌套对象
copied.address.city = "Shanghai";

console.log(original.address.city); // "Shanghai"，原对象也被修改
```

常见浅拷贝方式：对于访问器属性， `Object.assign()` 会执行 “读取值 → 赋值给新对象” 的操作，不会保留 getter/setter 和属性描述符，最终变成普通的数据属性

```
const objectCopy = { ...original };
const assignedCopy = Object.assign({}, original);

const array = [1, { value: 2 }];
const arrayCopy = [...array];
```

### 深拷贝

深拷贝会递归复制所有层级的对象，生成完全独立的副本，修改嵌套对象不会影响原对象；
#### structuredClone

`structuredClone()` 使用结构化克隆算法，可以复制循环引用以及多种内建对象；

支持的类型：普通对象、数组、Date、RegExp、Map、Set、ArrayBuffer、TypedArray、Blob、File 等内置类型；

主要限制：

- 不能克隆函数；
- 不能克隆 Symbol 值；
- 不复制 Symbol 键属性；
- 通常不会保留用户自定义类的原型语义；
- 不会完整保留属性描述符、getter 和 setter；
- DOM 节点不能直接克隆，应使用 `cloneNode()`；
- WeakMap 和 WeakSet 不可枚举，也不能被结构化克隆；

```
const original = {
  createdAt: new Date(),
  tags: new Set(["js"]),
};
original.self = original; // 循环引用

const copied = structuredClone(original);

console.log(copied !== original);          // true，不是同一个对象
console.log(copied.self === copied);       // true，循环引用正确复制
console.log(copied.createdAt instanceof Date); // true，Date 类型保留
```

#### JSON 序列化

JSON 是文本数据交换格式：

- `JSON.stringify()`：将可序列化的 JavaScript 数据转换为 JSON 字符串；
- `JSON.parse()`：将 JSON 字符串解析为 JavaScript 数据；

```
const original = { name: "Alice", age: 18 };
const jsonStr = JSON.stringify(original);
const copied = JSON.parse(jsonStr);
```

主要局限性：

- 属性值为 `undefined`、Function、Symbol 时，该属性会被直接忽略；
- 数组中的上述值会被转换为 `null`；
- `NaN`、`Infinity`、`-Infinity` 会转换为 `null`；
- BigInt 类型默认会抛出 TypeError；
- Date 对象会被转换为 ISO 格式字符串，丢失 Date 类型；
- Map、Set 默认转换为空对象 `{}`；
- 不可枚举属性和 Symbol 键会被忽略；
- 自定义原型和属性描述符会全部丢失；
- 循环引用会直接抛出 TypeError。

定制转换：可以通过`JSON.stringify` 的第二个参数 `replacer` 和 `JSON.parse` 的第二个参数 `reviver` 可以定制转换过程

```
const original = { createdAt: new Date("2026-01-01") };

// 序列化
const json = JSON.stringify(original, (key, value) => {
  return value; // 可自定义过滤或转换
});

// 反序列化，还原 Date
const data = JSON.parse(json, (key, value) => {
  if (key === "createdAt") {
    return new Date(value);
  }
  return value;
});
```

#### 手写深拷贝

当需要定制深拷贝逻辑时，可以手动实现。完整的深拷贝需要处理：循环引用、原型、属性描述符、Symbol 键以及常见内建对象，但仍不尝试复制函数闭包、WeakMap、WeakSet、Promise 和宿主对象；

```
function deepClone(value, seen = new WeakMap()) {
  // 原始值和 null 直接返回
  if (value === null || typeof value !== "object") {
    return value;
  }

  // 处理循环引用
  if (seen.has(value)) {
    return seen.get(value);
  }

  // 处理 Date
  if (value instanceof Date) {
    return new Date(value.getTime());
  }

  // 处理 RegExp
  if (value instanceof RegExp) {
    const result = new RegExp(value.source, value.flags);
    result.lastIndex = value.lastIndex;
    return result;
  }

  // 处理 Map
  if (value instanceof Map) {
    const result = new Map();
    seen.set(value, result);
    for (const [key, item] of value) {
      result.set(deepClone(key, seen), deepClone(item, seen));
    }
    return result;
  }

  // 处理 Set
  if (value instanceof Set) {
    const result = new Set();
    seen.set(value, result);
    for (const item of value) {
      result.add(deepClone(item, seen));
    }
    return result;
  }

  // 处理数组和普通对象，保留原型
  const result = Array.isArray(value)
    ? []
    : Object.create(Object.getPrototypeOf(value));

  seen.set(value, result);

  // 遍历所有自有键（含 Symbol、不可枚举），保留属性描述符
  for (const key of Reflect.ownKeys(value)) {
    const descriptor = Object.getOwnPropertyDescriptor(value, key);
    
    if ("value" in descriptor) {
      // 数据属性：递归拷贝值
      descriptor.value = deepClone(descriptor.value, seen);
    }
    
    Object.defineProperty(result, key, descriptor);
  }

  return result;
}
```

## 原型与构造函数

### 构造函数

可以通过 `new` 调用的函数称为构造函数；普通函数声明和普通函数表达式通常可构造，而箭头函数不能构造；

构造函数名称通常使用大驼峰命名，用于提示调用者应配合 `new`；

```
function User(name) {
  this.name = name;
}

User.prototype.sayHello = function () {
  return `Hello, ${this.name}`;
};

const user = new User("Alice");
```

### new 的执行过程

执行 `new Constructor(...args)` 时，可以概括为：

1. 创建一个新对象；
2. 把新对象的 `[[Prototype]]` 设置为构造函数的 `prototype`；
3. 以新对象作为 `this` 调用构造函数；
4. 如果构造函数显式返回对象，则返回该对象；
5. 否则返回新创建的对象；

```
function User(name) {
  this.name = name;
}

const user = new User("Alice");
```


### 构造函数的 `prototype` 属性

普通函数声明和函数表达式作为构造函数时，都会默认自带一个 `prototype` 属性（一个普通对象），我们称之为原型对象；箭头函数和绑定函数（`bind` 返回的函数）没有自己的 `prototype` 属性。我们常见的 `Object.prototype`、`Array.prototype`、`Function.prototype`，都属于对应构造函数自带的原型对象；

作为该构造函数所有实例的共享属性仓库：把实例通用的方法、属性挂载到 `prototype` 上，所有通过 `new` 创建的实例都可以访问到这些内容，避免每次创建实例都重复生成相同的函数，有效节省内存；

当执行 `new 构造函数()` 创建实例时，JavaScript 引擎会自动完成一个关键操作：将新实例内部隐藏的 `[[Prototype]]` 槽，指向该构造函数的 `prototype` 属性值

这里的原型有两层含义：

1. 对象的原型（内部槽 `[[Prototype]]`）：每个普通对象都有一个隐藏的内部槽 `[[Prototype]]`，它指向另一个对象（或 `null`），这个被指向的对象就是该对象的原型。当访问对象自身不存在的属性时，JavaScript 会自动去它的原型上继续查找。
2. 构造函数的 `prototype` 属性：每个构造函数都自带一个 `prototype` 属性（如`Object.prototype`,`Array.prototype`），它本身就是一个原型对象。通过 `new 构造函数()` 创建的所有实例，内部的 `[[Prototype]]` 都会自动指向这个 `prototype` 对象，从而让所有实例共享原型上的方法，避免重复创建。

```
function User(name) {
  this.name = name;
}

// 共享方法定义在构造函数的 prototype 上
User.prototype.sayHello = function () {
  return `Hello, ${this.name}`;
};

const first = new User("Alice");
const second = new User("Bob");

// 两个实例共享同一个原型方法
console.log(first.sayHello === second.sayHello); // true
```

### 对象的 `[[Prototype]]` 内部槽

每个普通对象都有一个隐藏的内部槽 `[[Prototype]]`，它是原型链的底层实现，外部无法直接访问； 这个槽里存储着一个引用，指向另一个对象（或 `null`），这个被指向的对象，就是该对象的原型；

`[[Prototype]]` 的指向由对象的创建方式决定，并非一定指向构造函数的 `prototype`：

- `new 构造函数()` 创建：实例的 `[[Prototype]]` 指向对应构造函数的 `prototype` 属性；
- 对象字面量 `{}` 创建：等价于 `new Object()`，`[[Prototype]]` 指向 `Object.prototype`；
- `Object.create(proto)` 创建：新对象的 `[[Prototype]]` 直接指向传入的 `proto` 对象，不涉及构造函数；
- 顶层 `Object.prototype`：它的 `[[Prototype]]` 为 `null`，是所有原型链的最终终点；

操作原型优先使用官方标准方法：

```
Object.getPrototypeOf(object); // 读取对象的原型
Object.setPrototypeOf(object, prototype); // 设置对象的原型
Object.create(prototype); // 创建一个以指定对象为原型的新对象
```

### `__proto__` 访问器属性

`__proto__` 既不是实例自身的属性，也不是某个原型对象独有的属性，它是定义在 `Object.prototype` 上的访问器属性（包含 `get` 和 `set` 函数）;

它是一套历史遗留的读写接口，用来间接操作对象内部隐藏的 `[[Prototype]]` 槽（`__proto__` 只是访问接口，不等于 `[[Prototype]]` 内部槽本身）：

- 读取 `obj.__proto__` 时：触发 `get` 函数，返回 `obj` 内部 `[[Prototype]]` 槽的指向；
- 赋值 `obj.__proto__ = xxx` 时：触发 `set` 函数，修改 `obj` 内部 `[[Prototype]]` 槽的指向；

所有普通对象（对象、数组、函数等）的原型链，最终都会追溯到 `Object.prototype`。把通用的 `__proto__` 定义在原型链的最顶端，所有对象只需通过原型链查找就能继承使用它，仅需定义一次，全局所有对象复用，最节省内存也最符合设计逻辑。同理，`toString()`、`hasOwnProperty()` 等通用方法，也都定义在 `Object.prototype` 上；

```
const obj = {}; // 普通实例对象

// 实例自身没有 __proto__ 属性
console.log(obj.hasOwnProperty('__proto__')); // false

// __proto__ 是 Object.prototype 自身的属性
console.log(Object.prototype.hasOwnProperty('__proto__')); // true
```
### constructor属性

每一个普通函数默认自带的 `prototype` 对象，都会自动生成一个 `constructor` 属性，指向函数本身，形成双向关联；

```
function User() {}

User.prototype.constructor === User; // true
```

整体替换 `prototype` 时，需要根据用途恢复 `constructor`：这里必须写 `constructor: User`，不能写成 `constructor: User()`，后者会调用函数并保存其返回值；

```
function User() {}

User.prototype = {
  constructor: User,

  sayHello() {
    return "hello";
  },
};
```

### 原型链

当读取对象的某个属性时，如果对象自身没有这个属性，JavaScript 会沿着 `[[Prototype]]` 向上逐级查找，直到找到该属性，或者到达原型链的末端 `null`。这个链式查找结构就是原型链；

```
const grandparent = { category: "base" };
const parent = Object.create(grandparent);
const child = Object.create(parent);

console.log(child.category); // "base" 沿原型链向上查找得到
```

### instanceof

`object instanceof Constructor` 默认检查 `Constructor.prototype` 是否出现在 `object` 的原型链上；

它主要判断原型链关系，不是通用类型判断，修改构造函数的 `prototype` 会影响结果；

```
function User() {}
const user = new User();

user instanceof User; // true
user instanceof Object; // true
```


## 类

### class 的本质

class 是 ES6 为 JavaScript 原型继承提供的语法糖，让原型继承的写法更清晰、更贴近传统面向对象语言，但底层仍然基于对象和原型链机制实现；

核心特征：

- class 本质上就是构造函数的另一种写法，`typeof 类名` 返回 `"function"`，类本身就对应构造函数本身；
- 类声明存在变量提升，但在初始化完成前无法访问，和 `let`、`const` 一样遵循暂时性死区规则；
- 类体内部默认启用严格模式，无需手动声明；
- 类中定义的普通方法，都会被挂载到 `类.prototype` 上，由所有实例共享；并且这些原型方法默认是**不可枚举**的，这是和传统构造函数写法的重要区别；

```
class User {
  constructor(name) {
    this.name = name;
  }
  sayHello() {
    return `Hello, ${this.name}`;
  }
}

console.log(typeof User); // "function"
console.log(User === User.prototype.constructor); // true，类本身就是构造函数
```

### constructor构造器

`constructor` 是类的构造函数，在使用 `new` 创建类实例时自动执行，用于初始化实例属性、执行初始化逻辑；

未显式定义时：

- 基类（无继承的类）：自动生成一个空构造器 `constructor() {}`
- 派生类（有继承的类）：自动生成默认构造器，等价于 `constructor(...args) { super(...args); }`

```
class User {
  constructor(name, age = 18) {
    this.name = name;
    this.age = age;
  }
}

const user = new User("Alice");
```


### 实例属性与实例方法

实例属性：直接在类体中定义的字段（也叫类实例属性），会在每个实例上单独创建，属于实例的自有属性，不会在原型上共享

实例方法：类中定义的普通函数方法，会挂载到 `类.prototype` 上，所有实例共享同一份函数；

```
class Counter {
  count = 0; // 实例字段：每个实例独立一份
  increment() { // 实例方法：原型共享
    this.count++;
    return this.count;
  }
}

const first = new Counter();
const second = new Counter();

console.log(first.increment === second.increment); // true 方法共享
console.log(Object.hasOwn(first, "count")); // true   count 是实例自有
console.log(Object.hasOwn(first, "increment")); // false increment 在原型上
```
把箭头函数写成实例字段，可以固定函数内的 this 指向（永远指向当前实例），但代价是每个实例都会创建一份独立的箭头函数，无法共享，实例数量多的时候会增加内存占用；

```
class ButtonController {
  handleClick = () => {
    console.log(this);
  };
}
```

### 静态字段与静态方法

用 `static` 关键字修饰的成员，属于类本身，不属于实例，只能通过类名访问。

核心特性：

- 静态成员挂载在类对象自身上，而非原型对象；
- 静态方法中的 `this` 通常指向调用该方法的类本身；
- 静态成员也会被子类继承；

```
class User {
  static type = "user"; // 静态字段
  
  static createAnonymous() { // 静态方法
    return new User("anonymous");
  }
  
  constructor(name) {
    this.name = name;
  }
}

console.log(User.type); // "user"
const guest = User.createAnonymous();
console.log(guest.name); // "anonymous"

// 实例无法访问静态成员
// console.log(guest.type); // undefined
```

### 私有字段与命名约定

JavaScript 没有 Java/C# 那样的语言级访问修饰符，字段可见性通过以下方式实现：

- 公有字段（public）：不加任何前缀，类内部、子类、类外部都可以访问；

- 私有字段（private）：使用 `#` 前缀，是 ES2022 的语法强制，只能在类内部通过 `this` 访问，外部和子类都无法访问；

- `_` 前缀：仅为社区命名约定，不提供任何语言级保护，外部仍可直接读写，通常用来暗示"建议仅内部使用"，相当于私有字段；

```
class Person {
    #age;  // # 表示私有字段，仅类内部可访问
    _name; // _ 仅为命名约定，外部仍可访问

    constructor(name, age) {
        this._name = name;
        this.#age = age;
    }
}
let a = new Person('aaa', 18);
```
### extends 与 super

`extends` 关键字用于建立类的继承关系，本质是建立两层原型链；`super` 用于访问父类的构造器和方法；

1. 实例原型链：`子类.prototype.__proto__` 指向 `父类.prototype`，实例可以继承父类的原型方法；
2. 静态继承链：`子类.__proto__` 指向 `父类`本身，子类可以继承父类的静态成员；

```
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);
    this.breed = breed;
  }
}
```

super 的两种用法

- `super(参数)`：调用父类的构造器。派生类的构造器中，访问 `this` 之前必须先调用 `super()`；
- `super.方法名()`：调用父类原型上的方法，常用于方法重写时复用父类逻辑；

```
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name); // 必须先调用 super 才能使用 this
    this.breed = breed;
  }
}
```

## JavaScript 继承

现代代码优先使用 `class extends` 表达构造器继承，或使用组合拆分能力；以下传统模式主要用于理解原型机制和维护旧代码：

### 原型链继承

让子构造函数的prototype指向父构造函数的实例对象

缺点：创建子实例对象时无法向父构造函数传参；所有子实例对象共享父的引用属性

```
    <script>
        //Father构造函数
        function Father(){
            this.money = 1000
        }
        //Child的构造函数
        function Child(){

        }
        //将Child的原型赋值为Fahter实例对象，以实现继承
        Child.prototype = new Father();

        let Child1 = new Child();
        console.log(Child1.money)
    </script>
```

### 盗用构造函数

又称“对象伪装”，“经典继承”，在子构造函数中通过调用父构造函数的call或apply将父的this指向子；相当于将父构造函数中的属性和方法复制到子构造函数中；

缺点：子构造函数和子实例与父的原型对象无联系，无法继承父亲写在prototype上的方法；由于父类必须在构造函数中定义方法，通过盗用构造函数继承的方法本质上都变成了实例自己的方法，不是公共的方法，因此失去了复用性；

```
    <script>
        //Father构造函数
        function Father(money){
            this.money = money
        }
        //Child的构造函数
        function Child(money){
            //将Father构造函数的this指向Child，并传参
            Father.call(this,money);
        }
        let Child1 = new Child(10000);
        console.log(Child1.money)
    </script>
```

### 组合继承

子先通过盗用构造函数继承父的属性，再通过原型链继承父的共享方法；

缺点：调用了两次父的构造函数

```
    <script>
        //Father构造函数
        function Father(money){
            this.money = money
        }
        Father.prototype.SayHi= function(){
            console.log('Hello')
        }
        
        //Child的构造函数
        function Child(money){
            Father.call(this,money);
        }
        Child.prototype = new Father();

        let Child1 = new Child(10000);
        console.log(Child1.money)
        Child1.SayHi();
    </script>
```

### 原型式继承

object 函数将原型式继承的核心代码封装成一个函数，基于已有的对象创建新对象，创建完后新对象的`__proto__`指向 prototype，再指向已有对象；在ES5新增了一个`Object.create()`方法将原型式继承规范化了；

缺点：不能传参；已有对象的引用数据类型会被新对象共享；

```
const object = function(o){//o是一个已有对象
     //创建临时构造函数
     function F(){}
     //将临时构造函数的原型对象指向o
     F.prototype = o
     //这个object函数的返回值是一个原型对象指向o的F实例对象
     return new F()
}
let Father = {
    money:10000,
}

let Child = object(Father);
console.log(Child.money)
```

### 寄生式继承

在原型式继承基础上增强对象；

```
const object = function(o){
    //原型式继承创建一个临时clone对象
    let clone = Object.create(o);
    clone.sayHi = function(){
        console.log('Hello');
    }
    return clone;
}
```

### 寄生式组合继承

通过盗用构造函数继承父的属性，通过混合寄生式继承和原型式继承来继承父原型对象中的方法

```
    <script>
        //Father构造函数
        function Father(money){
            this.money = money
        }
        Father.prototype.SayHi= function(){
            console.log('Hello')
        }
        //Child的构造函数
        function Child(money){
            //盗用构造函数继承父的属性并可传参
            Father.call(this,money);
        }
        //创建一个实现寄生式继承的函数,函数参数是引用
        function inherit(Father,Child){
            //创建一个临时存储Fatter的原型对象的对象
            let Fatherprototype = Object.create(Father.prototype);
            //将临时Fatherprototype的constructor指向Child，以便将临时Father赋值给Child的原型对象时的constructor不是Child构造函数
            Fatherprototype.constructor =Child;
            //将配置好的临时Fatherprototype赋值给Child的原型对象，实现了Child的原型对象指向Fahter，并且constructor指向Child构造函数
            Child.prototype = Fatherprototype;
        }
        inherit(Father,Child);
    </script>
```


### class 继承

现代语法使用 `extends` 和 `super`：

```
class Parent {
  constructor(name) {
    this.name = name;
  }

  sayHello() {
    return `Hello, ${this.name}`;
  }
}

class Child extends Parent {
  constructor(name, age) {
    super(name);
    this.age = age;
  }
}
```

类继承会同时建立两条关系：

```
Object.getPrototypeOf(Child.prototype) === Parent.prototype; // true
Object.getPrototypeOf(Child) === Parent; // true
```

前者用于继承实例方法，后者用于继承静态成员；
