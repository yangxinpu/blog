## ES版本

JavaScript 由三部分组成，分别承担语言核心、网页内容操作和浏览器交互的职责：

- ECMAScript（European Computer Manufacturers Association Script）：JS的语言核心，规定语法、类型、语句、关键字、操作符、全局对象等，标准来源为 ECMA 国际（ECMA-262 标准）；
- DOM（Document Object Model，文档对象模型）：把 HTML/XML 文档映射为树形结构，提供访问和操作页面元素的方法和接口，标准来源为 W3C / WHATWG；
- BOM（Browser Object Model，浏览器对象模型）：提供与浏览器窗口交互的方法和接口，可操作窗口、导航、屏幕、Cookie 等，由各浏览器厂商逐步形成事实标准，HTML5 后部分纳入规范。

各个ES版本：

- **ES1（1997）**：首个正式版本，确立了基本语法、数据类型、语句、函数等核心特性；

- **ES2（1998）**：主要是编辑性修订，使标准与 ISO/IEC 16262 保持一致；

- **ES3（1999）**：增加了正则表达式、`try/catch` 异常处理、`do-while` 语句、字符串处理增强、更完善的错误类型体系，是第一个被广泛采用的版本。

- **ES4（未发布）**：ES4 曾计划引入类、接口、命名空间、泛型等大量特性，因改动过于激进而在 2008 年被放弃，其部分理念后来融入了 ES6 和后续版本。

- **ES5**：是一个重要的稳定版本，新增特性包括：严格模式、原生JSON方法、数组方法、对象方法、访问器属性等；

- **ES6 / ES2015（2015）**：是 JavaScript 历史上最大的一次更新，奠定了现代 JS 的基础，主要特性：

	- 块级作用域：`let`、`const`；
	- 箭头函数 `=>`；
	- 类语法 `class`、`extends`、`super`；
	- `Promise`；
	- 模块化：`import` / `export`（ES Module）；
	- 模板字符串（反引号）；
	- 解构赋值（对象、数组）；
	- 默认参数、剩余参数 `...`、展开运算符；
	- `Symbol` 原始类型；
	- `Map`、`Set`、`WeakMap`、`WeakSet`；
	- 迭代器（Iterator）与生成器（Generator，`function*` / `yield`）；
	- `Proxy` 与 `Reflect`；
	- 二进制（`0b`）和八进制（`0o`）字面量；
	- `Number` 新增：`isFinite`、`isNaN`、`isInteger`、`isSafeInteger`、`EPSILON`、`MIN_SAFE_INTEGER`、`MAX_SAFE_INTEGER`；
	- `Math` 新增：`trunc`、`sign`、`cbrt`、`hypot` 等；
	- `Array.from()`、`Array.of()`、`Array.prototype.find/findIndex/fill/keys/values/entries`；
	- `Object.assign()`、`Object.is()`；
	- `String` 新增：`startsWith`、`endsWith`、`includes`、`repeat`；
	- `for...of` 循环。

- **ES2016（ES7）**：新增`Array.prototype.includes()`；指数运算符 `**`（如 `2 ** 3 === 8`）；

- **ES2017（ES8）**：新增`async` / `await` 异步函数；`Object.values()`、`Object.entries()`； `Object.getOwnPropertyDescriptors()`；

- **ES2018（ES9）**：新增异步迭代：`for await...of`、异步生成器； 对象展开运算符（`...` 在对象字面量中）； `Promise.prototype.finally()`；

- **ES2019（ES10）**：新增数组扁平化：`Array.prototype.flat()`、`flatMap()`； 字符串修剪：`String.prototype.trimStart()`、`trimEnd()`；可选的 `catch` 绑定（`catch {}` 可省略参数）； 数组 `sort()` 稳定排序。

- **ES2020（ES11）**： 新增`BigInt` 任意精度整数类型；可选链操作符 `?.`； `globalThis` 统一全局对象引用； 动态导入 `import()`； `import.meta`（如 `import.meta.url`）；

- **ES2021（ES12）**：新增 `String.prototype.replaceAll()`； 逻辑赋值运算符：`??=`、`&&=`、`||=`； `WeakRef` 与 `FinalizationRegistry`（弱引用与终结器）； 数字分隔符（`1_000_000`）。

- **ES2022（ES13）**：新增类字段：公有实例字段、私有实例字段（`#field`）；私有方法与私有访问器（`#method()`、`get #x()`）； 顶层 `await`（模块顶层）；

- **ES2023（ES14）**：新增数组不可变方法：`toReversed()`、`toSorted()`、`toSpliced()`、`with()`（返回新数组，不修改原数组）； `Symbol` 可作为 `WeakMap` 的键

- **ES2024（ES15）**： 新增`Promise.withResolvers()`； `Object.groupBy()`、`Map.groupBy()`；可调整大小的 `ArrayBuffer` 与可增长的 `SharedArrayBuffer`；

## JavaScript 的执行入口

### script 标签

`<script>`标签是浏览器加载、执行 JavaScript 的入口。对于未添加 async、defer 属性的经典脚本，会按照它在 HTML 里书写的顺序依次加载并执行；

浏览器解析 HTML 时一旦遇到`<script>`标签，就会暂停后续 HTML 的解析，等待脚本完成下载与执行，之后再恢复解析剩下的 HTML 内容；

`<script>`标签常见属性：

- `src`：指定外部脚本地址，当存在 `src` 时，标签内部的 JavaScript 代码会被忽略；
- `type`：脚本类型，省略时为经典脚本，设置为 `module` 时作为 ES Module （ESM）处理；
- `async`：脚本下载不阻塞 HTML 解析，加载完成后立即执行，执行时会暂停 HTML 解析；
- `defer`：脚本下载不阻塞 HTML 解析，等待HTML文档解析完成后按照文档顺序执行；
- `crossorigin`：控制跨源脚本请求的 CORS 模式；
- `integrity`：通过哈希校验外部资源内容，防止资源被意外篡改；

```
<script src="./main.js"></script>

<script async src="./analytics.js"></script>

<script defer src="./vendor.js"></script>
```

`defer` 只对带 `src` 的经典脚本有实际意义，而ESM默认具有 `defer` 的行为；给ESM添加 `async` 后，它会在依赖加载完成后立即执行，不再等待HTML解析完成；

### 经典脚本与 ES Module

经典脚本和模块脚本具有不同的作用域及加载语义；

| 特性        | 经典脚本             | ES Module     |
| --------- | ---------------- | ------------- |
| 严格模式      | 需要手动开启           | 默认开启          |
| 顶层作用域     | 多个经典脚本可共享全局作用域   | 每个模块拥有独立模块作用域 |
| 顶层 `this` | 浏览器中通常为 `window` | `undefined`   |
| 加载方式      | 默认阻塞 HTML 解析     | 默认defer延迟执行   |

浏览器中的 ES 模块，需要通过 HTTP 或者 HTTPS 协议加载。如果直接以`file://`协议打开本地网页，同源策略会阻止模块请求。因此开发 ES Module 项目，通常需要启动本地服务器；

```
<!-- 经典脚本 -->
<script src="./legacy.js"></script>

<!-- ES模块脚本 -->
<script type="module" src="./main.js"></script>
```

### 严格模式

经典脚本或普通函数可以通过 `"use strict"` 开启严格模式；而ES Module 和类体默认处于严格模式；

严格模式的主要变化：

- 禁止给未声明的标识符赋值；
- 普通函数直接调用时，`this` 不会被自动替换为全局对象；
- 禁止使用 `with`；
- 禁止删除不可删除的属性，以及删除由声明创建的标识符；
- 函数参数名不能重复；
- 部分原本静默失败的操作会抛出异常；
- 直接调用 `eval()` 时，其中的声明不会泄漏到外层作用域；

```
"use strict";

function run() {
  console.log(this); // undefined
}

run();
```
