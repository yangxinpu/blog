# 前端

前端开发技术栈学习笔记，包含 HTML、CSS、JavaScript、React、Vue、前端工程化等主流技术。

## 模块概览

- **HTML** - 页面结构与语义化基础
- **CSS** - 样式、布局与视觉表现
- **JavaScript** - JavaScript 基础与进阶知识
- **React** - React 框架学习笔记
- **Vue** - Vue 框架学习笔记
- **Vite** - 现代前端构建工具
- **Webpack** - 前端工程构建与打包
- **前端工程化** - 规范、构建、质量和发布流程
- **性能优化** - 页面性能和资源优化
