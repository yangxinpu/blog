# Performance Testing

## What is Performance Testing

Performance testing validates system behavior under various load conditions.

## Types

- **Load Testing**: Simulate normal production load
- **Stress Testing**: Push beyond normal limits to find bottlenecks
- **Soak Testing**: Long-running tests to identify memory leaks
- **Spike Testing**: Sudden load increases

## Common Tools

- **JMeter**
- **k6**
- **Locust**
- **Gatling**
