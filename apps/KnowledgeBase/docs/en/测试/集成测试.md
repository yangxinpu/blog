# Integration Testing

## What is Integration Testing

Integration testing verifies that different modules work correctly when combined together.

## Testing Strategies

1. **Bottom-Up**: Test low-level modules first, then gradually integrate
2. **Top-Down**: Test high-level modules first with stubs for lower-level modules
3. **Hybrid**: Combine both approaches

## Example Scenarios

- API interface testing
- Database operation testing
- Third-party service integration testing
