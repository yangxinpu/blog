# 国际化（i18n）

VitePress 通过目录结构和配置实现多语言站点。

## 目录结构

```
docs/
├─ .vitepress/config.ts        # 共享配置
├─ zh/
│  ├─ index.md                 # /zh/
│  └─ guide/
│     └─ getting-started.md    # /zh/guide/getting-started
└─ en/
   ├─ index.md                 # /en/
   └─ guide/
      └─ getting-started.md    # /en/guide/getting-started
```

## 配置方式

### 方式一：每个语言单独配置

```ts
// .vitepress/config/zh.ts
import { defineConfig } from 'vitepress'
export default defineConfig({
  lang: 'zh-CN',
  title: '我的站点',
  description: '一个 VitePress 站点',
  themeConfig: { nav: [...], sidebar: {...} }
})
```

```ts
// .vitepress/config/en.ts
import { defineConfig } from 'vitepress'
export default defineConfig({
  lang: 'en-US',
  title: 'My Site',
  description: 'A VitePress site',
  themeConfig: { nav: [...], sidebar: {...} }
})
```

```ts
// .vitepress/config.ts
import { defineConfig } from 'vitepress'
import zh from './config/zh'
import en from './config/en'

export default defineConfig({
  // 非语言特定配置
  title: 'VitePress',
  
  locales: {
    'zh': { label: '简体中文', ...zh },
    'en': { label: 'English', ...en }
  }
})
```

### 方式二：在根配置中定义

```ts
export default defineConfig({
  locales: {
    'zh': {
      label: '简体中文',
      lang: 'zh-CN',
      title: '我的站点',
      description: '一个 VitePress 站点',
      themeConfig: {
        nav: [{ text: '指南', link: '/zh/guide/' }],
        sidebar: { '/zh/guide/': [...] }
      }
    },
    'en': {
      label: 'English',
      lang: 'en-US',
      title: 'My Site',
      description: 'A VitePress site',
      themeConfig: {
        nav: [{ text: 'Guide', link: '/en/guide/' }],
        sidebar: { '/en/guide/': [...] }
      }
    }
  }
})
```

## 语言切换

配置 `locales` 后，导航栏自动显示语言切换下拉菜单。

## 默认语言

根目录的 `index.md` 对应默认语言。或通过 `locales` 的根键 `/` 定义默认语言：

```ts
export default defineConfig({
  locales: {
    '/': {
      label: 'English',
      lang: 'en-US',
      // ...
    },
    '/zh/': {
      label: '简体中文',
      lang: 'zh-CN',
      // ...
    }
  }
})
```

## 禁用 i18n 路由

```ts
export default defineConfig({
  themeConfig: {
    i18nRouting: false
  }
})
```
